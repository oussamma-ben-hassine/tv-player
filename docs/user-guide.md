# Guide Utilisateur — TV Player

## Prise en Main

1. Rendez-vous sur `https://tv.oussamma.tn`.
2. Cliquez sur **Se connecter via SSO** et validez votre connexion avec votre compte unifié `oussamma.tn`.
3. Dès la connexion, la dernière chaîne regardée ou la première chaîne de la liste se lance automatiquement dans le lecteur.

## Navigation & Commandes

### Sur Ordinateur (Desktop)
- **Panneau de gauche :**
  - Recherchez une chaîne par son nom, pays ou langue.
  - Filtrez par catégorie via les pastilles horizontales.
  - Cliquez sur l'étoile pour basculer en mode *Favoris uniquement*.
  - Repliez le panneau gauche à tout moment avec le bouton *Replier le panneau* pour agrandir le lecteur.
- **Lecteur vidéo (Zone droite) :**
  - Basculez entre les résolutions (Auto, 1080p, 720p, etc.) depuis le menu Qualité.
  - Ajustez le volume avec le curseur (0 à 100%) ou coupez le son avec le bouton muet.
  - Activez le mode plein écran natif (ou appuyez sur la touche `F`).
  - Activez l'Image dans l'Image (PiP) pour continuer à regarder la télévision tout en naviguant sur une autre fenêtre.

### Sur Mobile & Tablette
- Le lecteur s'affiche en haut de l'écran en ratio 16:9 optimisé.
- La liste des chaînes et les catégories défilent sous le lecteur.
- Le mode plein écran s'adapte automatiquement à l'orientation paysage de votre smartphone.
- L'application est installable comme une application native (PWA) depuis le menu de votre navigateur (*Ajouter à l'écran d'accueil*).
